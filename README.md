# Rastaroots Life Website

Static website package for GitHub Pages.

## Upload to GitHub Pages

1. Create a new GitHub repository called `rastarootslife`.
2. Upload these files into the repository root:
   - `index.html`
   - `styles.css`
   - `script.js`
   - `assets/`
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/root`
5. Save.
6. Connect your domain `rastarootslife.com` in GitHub Pages.
7. Replace the form action in `index.html`:
   `https://formspree.io/f/YOUR_FORM_ID`
